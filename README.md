# 📐 Distância entre Dois Pontos 

Este projeto foi desenvolvido em **Java** para calcular a distância entre dois pontos no espaço tridimensional.

O programa recebe as coordenadas de dois pontos:

* Ponto A → `(xA, yA, zA)`
* Ponto B → `(xB, yB, zB)`

E calcula a distância entre eles utilizando a fórmula da distância euclidiana em três dimensões.

## 🧮 Fórmula

A distância entre os pontos A e B é calculada por:

```text
d = √((xB - xA)² + (yB - yA)² + (zB - zA)²)
```

## 💻 Tecnologias

* Java
* `Scanner`
* `Math.sqrt()`
* `Math.pow()`

## 📋 Funcionamento

O programa:

1. Lê as coordenadas `x`, `y` e `z` do ponto A.
2. Lê as coordenadas `x`, `y` e `z` do ponto B.
3. Calcula a distância entre os dois pontos.
4. Exibe o resultado na tela.

## ▶️ Exemplo de entrada

```text
1 2 3
4 6 8
```

## 📤 Exemplo de saída

```text
7.0710678118654755
```
